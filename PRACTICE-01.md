# Bài thực hành 01 — Requirement

## Tình huống

Team đang sử dụng Git để quản lý tài liệu Requirement. Bạn được yêu cầu cập nhật Requirement của dự án.

## Task 1 — Clone

Clone repository về máy.

## Task 2 — Branch

Tạo một branch riêng cho bài thực hành. Không làm việc trực tiếp trên `main`.

## Task 3 — Update Requirement

Mở [requirement.md](requirement.md) và thêm yêu cầu sau vào phần **User Requirement**:

Người dùng có thể tạo và chỉnh sửa tài liệu của dự án.

## Task 4 — Commit

Lưu thay đổi bằng một commit phù hợp.

## Task 5 — Push

Đưa branch của bạn lên remote.

## Task 6 — Update main

Người hướng dẫn sẽ cập nhật một thay đổi mới trên `main`. Sau khi thay đổi được cập nhật, đưa thay đổi mới nhất từ `main` vào branch của bạn.

## Task 7 — Resolve Conflict

Trong quá trình merge sẽ phát sinh một conflict đơn giản trong [requirement.md](requirement.md). Hãy:

- Xác định phần conflict.
- Xác định nội dung phù hợp cần giữ.
- Hoàn tất việc giải quyết conflict.
- Commit kết quả.
- Push branch lên remote.

## Expected Result

Branch của bạn trên remote phải:

- Có thay đổi Requirement.
- Có commit.
- Đã cập nhật thay đổi mới từ `main`.
- Đã xử lý conflict.
- Đã push thành công.
