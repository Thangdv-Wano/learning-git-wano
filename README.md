# Git Basic Practice

Đây là repository dùng cho bài thực hành Git Basic Training.

## Mục tiêu

Người tham gia cần thực hiện được workflow Git cơ bản trong quá trình làm việc với tài liệu dự án.

## Thời gian

25 phút.

## Workflow cần thực hiện

Clone → Create Branch → Checkout → Edit → Add → Commit → Push → Pull → Merge → Resolve Conflict → Commit → Push

## Lưu ý

- Không làm việc trực tiếp trên `main`.
- Tạo branch riêng trước khi chỉnh sửa.
- Commit các thay đổi của bạn.
- Push branch lên remote.
- Trong quá trình thực hành sẽ có một conflict đơn giản.
- Tự xử lý conflict và hoàn tất merge trước khi kết thúc bài.
